# Holiday planner template

Instructions and a starting page for getting an AI agent to build a phone-friendly holiday planner: dog-friendly walks, breakfasts, lunches, dinners, towns, food shops and essentials near where we're staying, with distances, Google Maps links, verified websites and credited photos, published on GitHub Pages.

- [`AGENTS.md`](AGENTS.md): the instructions. Point the agent at it.
- [`reference/index.html`](reference/index.html): the finished Forest of Dean planner to copy ([live](https://waterdrips.github.io/forest-of-dean-trip/)).
- [`tools/photos.py`](tools/photos.py): fetches freely licensed Wikimedia Commons photos with credits.

## Use it

Prompt something like:

> Using github.com/Waterdrips/holiday-planner-template/AGENTS.md, build us a holiday planner. We're staying at <address> from <date> to <date>: <who's coming; are we taking the dog and the baby?>. <How often you'll eat out, preferences.>
